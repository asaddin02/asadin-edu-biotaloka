## 2. Apa targetnya?

Target produk yang tercatat adalah atlas biologi gratis, dwibahasa, untuk siswa SD sampai mahasiswa dan guru: materi berjenjang, eksplorasi spesies bersumber, kuis, simulasi, dan dukungan kegiatan belajar.

Target perubahan hari ini adalah **menerbitkan dua kanal dukungan yang sudah dikonfigurasi**, mempertahankan perilaku kanal kosong/tidak valid, serta memastikan cache PWA diperbarui. Pembayaran berlangsung di layanan eksternal; aplikasi tidak menyimpan kredensial atau memproses transaksi.

Target konten berikutnya merujuk [bagian B.5 audit](AUDIT-BIOLOGY.md#b5-yang-masih-belum-tersedia-dan-keterbatasan): rujukan per fakta kartu spesies, pengayaan kolom bila ada sumber, empat topik khusus yang belum tersedia, foto yang hilang, pencocokan kurikulum resmi, dan telaah guru/ahli. Tidak ada manifest batch atau target jumlah total kartu baru yang disepakati seperti pada Mitoloka.

## 3. Berapa entri lagi yang perlu dilanjutkan?

| Pekerjaan tersisa yang dapat dihitung | Cakupan |
|---|---:|
| Menambahkan rujukan per fakta pada teks kartu kurasi | **160 kartu** |
| Foto berlisensi dengan asal-usul jelas | **1 kartu: Thermus aquaticus**, ID `5426400` |

| Kartu tanpa kolom umur | **121 dari 160**, hanya diisi bila sesuai organisme dan tersedia sumber andal |
| Rencana jumlah kartu baru di luar 160 yang sudah ada | **Belum ditetapkan** |

**Jangan menjumlahkan angka-angka tersebut menjadi total entri baru.** Foto dan umur merupakan bagian dari kartu yang sama. Sebagian organisme tidak cocok diperlakukan seperti hewan dengan satu angka umur maksimum.

Pemeriksaan struktur data menunjukkan belum ada field `sources`, `references`, atau `citations` pada 160 kartu. Ini sesuai catatan audit bahwa teks deskripsi, makanan, habitat, dan fakta seru belum memiliki rujukan per fakta. Identitas GBIF/iNaturalist, atribusi foto, dan penyebutan AnAge untuk data umur sudah ada, tetapi tidak menggantikan rujukan bagi setiap klaim teks.

Belum tersedia hitungan tuntas untuk kurasi pemangsa, mangsa, perilaku, siklus hidup, pencocokan Capaian Pembelajaran, dan telaah ahli. Jangan melaporkan “tinggal 0 entri” hanya karena validasi dan tes aplikasi lulus.

## Pemeriksaan dan publikasi

Pemeriksaan sebelum commit telah lulus: `npm run check` (lint, validasi data, konsistensi precache, dan **86/86 tes browser**) serta `npm run build:site` (2.117 berkas, 66,4 MB, termasuk snapshot lokal). Versi precache sesuai `bbd60d217848`.

Validasi data memiliki **satu peringatan yang sudah dikenal: Thermus aquaticus belum mempunyai foto**. Tes teknis tidak membuktikan seluruh klaim biologi telah ditelaah ahli, dan pengujian tombol donasi tidak melakukan transaksi pembayaran.

Push ditujukan ke **`origin/main` pada `asaddin02/asadin-edu-biotaloka`**. Workflow CI akan menjalankan tes serta build Docker; setelah berhasil, workflow Deploy menerbitkan situs ke Cloudflare Pages. Snapshot API dipulihkan dari cache bila tersedia; rekaman baru memerlukan waktu lebih lama. Pantau hasil terbaru di [GitHub Actions](https://github.com/asaddin02/asadin-edu-biotaloka/actions).

Sebelum push ini, situs live masih memuat konfigurasi kanal donasi kosong. Setelah deploy selesai, verifikasi kedua nilai di `/js/config.js`, versi `/sw.js`, dan tombol di [Dukung Biotaloka](https://biotaloka.pages.dev/#/dukung). Pengguna PWA mungkin perlu menerima pembaruan aplikasi atau memuat ulang.

## Melanjutkan dari PC lain

Dari checkout yang bersih:

```bash
git pull --ff-only origin main
npm ci
cat docs/HANDOFF-2026-10-02.md
npm run check
npm run dev
```

Preview lokal: `http://127.0.0.1:8085/#/dukung`. Jika mengubah kode aplikasi, jalankan **`npm run build`** sebelum commit agar `sw.js` sesuai. Build static hosting memakai `npm run build:site`.

Mulai pekerjaan konten dari [audit B.5](AUDIT-BIOLOGY.md#b5-yang-masih-belum-tersedia-dan-keterbatasan) dan [data kartu](../js/data/species.js). Tentukan kelompok kartu yang akan dikerjakan, baca sumber sebenarnya, lalu catat rujukan yang mendukung klaim; tidak perlu menulis ulang 41 topik yang sudah ada dari nol.
